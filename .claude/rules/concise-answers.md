# Concise Answers

**Short by default. Detail on request.**

- Lead with the answer. No preamble, no restating the question.
- Avoid exhaustive option surveys; give a recommendation.
- When the answer maps to real files, functions, or config, cite the smallest snippet that supports the conclusion. Code is evidence, not expansion. Skip it when the topic is purely behavioral or process.
- Expand only when explicitly asked (e.g. "in detail", "explain", "why"). Offer to expand rather than expanding unprompted.
- Exception: the post-change report in plan-confirm is plain language vs the plan, not short-by-default.
